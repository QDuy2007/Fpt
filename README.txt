# GONLEFOOD Pizza Website

Website landing page bán pizza lấy cảm hứng từ giao diện mẫu bạn gửi.

## Chạy
1. Giải nén thư mục.
2. Mở `index.html` bằng trình duyệt.
3. Không cần PHP/MySQL để xem giao diện.

## Có sẵn
- Header cố định + responsive mobile menu
- Hero / câu chuyện thương hiệu / thống kê
- Thực đơn 8 pizza
- Lọc theo danh mục
- Tìm kiếm pizza
- Sắp xếp theo giá / đánh giá
- Yêu thích lưu bằng localStorage
- Giỏ hàng: thêm, tăng giảm số lượng, xóa
- Quick view sản phẩm
- Checkout demo
- Countdown ưu đãi
- Sao chép mã khuyến mãi
- Form liên hệ
- Theo dõi đơn hàng demo
- Footer + newsletter
- Hiệu ứng hover, blur, glass, scroll, back-to-top
- Responsive desktop/tablet/mobile

## Lưu ý
Ảnh món ăn đang dùng ảnh online từ Unsplash để file nhẹ. Khi làm bản nộp Laragon/PHP, có thể thay URL ảnh bằng thư mục `assets/images/` và nối database MySQL.
